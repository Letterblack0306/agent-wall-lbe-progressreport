What the Prototype Gets Wrong

  • ❌ No runtime transport — No fetch, WebSocket, PTY, or child-process bridge
  • ❌ Hard-coded state — All data is static in terminal-engine.ts
  • ❌ Missing AUDIT mode — Canonical LBE requires PLAN / ACT / AUDIT
  • ❌ Simulated delays — setTimeout with Math.random() for process duration
  • ❌ No LbeWrapper integration — Cannot connect to RealLbeWrapper
  • ❌ No Cline provider binding — Cannot receive real provider/model state
  • ❌ No BirdEye MCP query — Cannot query workspace/memory/skills
  • ❌ Not TTY/ConPTY — Browser-based, not terminal-native
